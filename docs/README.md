# SAGAR-VIEW

**SIH 2026 — Problem Statement 26067**

> "Develop a web-based interactive 3D visualization platform that integrates numerical ocean model outputs and in-situ observations."

SAGAR-VIEW is a browser-native interactive 3D ocean visualization platform for the Indian Ocean. Numerical model fields (temperature, salinity, currents, SSH) and real Argo float observations are visualized, explored, and compared in a single unified interface.

---

## Quick Start

### 1 — Generate demo data (one-time)

```bash
cd backend
python -m pip install -r requirements.txt
python scripts/generate_demo_data.py
python scripts/validate_netcdf.py data/demo/indian_ocean_demo.nc
```

### 2 — Start the backend

```bash
cd backend
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

API docs: http://localhost:8000/docs

### 3 — Start the frontend

```bash
cd frontend
npm install
npm run dev
```

App: http://localhost:3000

## Architecture

```
Browser (Next.js 14 + Three.js)
  ├── WebGL globe (Three.js ShaderMaterial + DataTexture)
  ├── React panels (variable, time/depth, observation drawer)
  ├── Recharts (profile & time-series charts)
  └── REST fetch ──→ FastAPI (Python)
                          ├── /api/datasets    → xarray metadata
                          ├── /api/fields      → 2D depth-slice
                          ├── /api/currents    → u/v vector field
                          ├── /api/observations→ Argo platforms
                          ├── /api/profiles    → depth profiles + collocation
                          └── /api/export      → CSV / JSON download
```

## Key Technical Decisions

| Concern | Choice |
|---------|--------|
| Globe rendering | Three.js + custom GLSL ShaderMaterial |
| State management | Zustand |
| Data fetching | TanStack React Query |
| Data transport | JSON (Protobuf upgrade path documented) |
| Observation source | Argovis REST API + synthetic fallback |
| Caching | In-memory LRU + optional Redis |
| Demo data | Deterministic synthetic NetCDF (offline) |
| Colormaps | Thermal, Haline, Speed, Balance, Viridis, Jet |

## Demo Dataset

The synthetic Indian Ocean demo dataset is generated by `generate_demo_data.py`:

- **Grid**: 1/4° resolution, 40–100°E, 30°S–30°N (241×241 points)
- **Time**: 12 monthly steps (2023-01 to 2023-12)
- **Depth**: 20 levels (5 m – 2000 m)
- **Variables**: `thetao` (°C), `so` (PSU), `uo` (m/s), `vo` (m/s), `zos` (m)
- **Observations**: 40 synthetic Argo float profiles

All values are physics-inspired synthetic data. **Not for scientific use.**

## Limitations

- Demo data is synthetic — not validated oceanographic model output
- WebGL 2.0 required (modern browsers only)
- No authentication or multi-user support in MVP
- Real CMEMS/INCOIS data requires credentials and adapter configuration
